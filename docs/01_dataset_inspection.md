## 9. Failure-label investigation

- **No label column exists.** The PDF states: "The dataset is unlabeled".
- Ground truth = 4 air-leak windows from company reports (table in PDF, copied verbatim into `configs/config.yaml`).
- **Inconsistencies in the official table (documented, not altered):** two rows are numbered "#1"; event 2 (29 May) lists "Maintenance on 30Apr", which precedes it and likely belongs to event 1.

- Rows inside any failure window: **29,954 (1.97%)** → imbalance ratio ≈ 1:50.
- Only **4 independent events** → any supervised metric rests on very few events and must be reported per event.
- LPS (low-pressure switch) is not a usable label: it never fires during event(s) [1, 2].
- Mean TP3 (panel pressure) is lower inside every failure window than outside — consistent with an air leak and a first hint of a learnable signal.
